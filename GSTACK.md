# GSTACK — Skill Catalog

**Usage**: Reference for browsing-tool selection and gstack skill lookup by category.

## Browsing Strategy

| Task | Primary Tool | Fallback |
|---|---|---|
| Library docs (React, Django, Prisma, etc.) | **context7 MCP** | — |
| General web browsing (articles, research) | **gstack `/browse`** | **playwright MCP** |
| Page scraping | **gstack `/scrape`** | **playwright MCP** |
| Debug, performance, a11y audit | **chrome-devtools-mcp** | — |
